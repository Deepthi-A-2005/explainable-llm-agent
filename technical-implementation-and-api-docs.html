Technical notes

A simple contract for future model adapters.

The current browser implementation is intentionally self-contained. Its explanation fields can later become the contract between a real FastAPI model service and the research UI.

Prediction contract

intent                 final route (or "fallback")
candidateIntent        best-scoring intent before abstention
confidence             0–0.98
alternatives[]         {id, score}
entities[]             {type, value, start, end}
contextContribution    {intent, weight, source} | null
thresholdDecision      {threshold, abstained}
modelVersion           e.g. rule-based-v1.3-context
featureContributions[] {text, weight, type}

This is exactly the object returned by classify() in js/shared.js.

Future API boundary

POST /api/v1/intent
POST /api/v1/chat
GET  /api/v1/evaluation

No API key is required by the current static prototype.
API shape is documented as an upgrade boundary, not a claim that these endpoints are live.
