Context mechanism

Small memory. Explicit carryover.

The prototype keeps the four most recent user turns (text + routed intent) available to the router. A previous intent can contribute a fixed, inspectable weight only when the new message is short and weakly specified.

Routing rule

Carryover = +0.6

Assistant replies are not stored in the window, and turns routed to fallback are skipped when looking for an intent to carry over. The carryover is intentionally small. It is applied only when the current message has weak evidence and seven or fewer words. The explanation panel states when it was used.

Clear memory

Clearing routing memory removes future context influence without deleting the visible conversation transcript.

Context is treated as a measurable input, not an invisible state.
