Core contribution

Transparency is implemented, not narrated.

The prototype exposes the evidence used by its actual deterministic scorer. It does not generate a fictional chain-of-thought or pretend the local fallback is a trained LLM.

◎

Feature attribution

Matched keywords and phrases are shown with their configured score contribution, alternatives, threshold decision, and model version.

↺

Context-aware routing

A small bounded context window can carry the previous intent into short ambiguous follow-ups. The carryover is visible and weighted.

▣

Evaluation first

A hand-authored development set and cue-removal sensitivity test make the behavior reproducible without claiming an external benchmark.

Research questions

What comes next?

Paraphrase stability

How stable is transparent routing when surface wording changes?

Context utility

Does bounded carryover improve short follow-up routing without increasing false associations?

Faithfulness

Do cited cues predict the score change observed when those cues are masked?

Non-claims

What this prototype is not.

The current local implementation is deterministic and rule-based. SHAP, LIME, attention attribution, external RAG retrieval, trained neural inference, and production performance claims are future work—not hidden behind the UI.
