Reproducibility

Portable by design.

The prototype has no build step and no secret dependency for its local behavior. Reviewers can inspect the files and run the interaction locally.

Run

Local setup

python3 -m http.server 8080
# then browse to http://localhost:8080/

# reproduce the evaluation (and verify Python == JS)
python3 tools/evaluate.py --table --check-js
Release discipline

What is tracked?

  • Classifier version string and weights (js/model.js)
  • Development examples (data/dev_set.json)
  • Evaluation definitions
  • Explicit future-work boundary
  • No committed API keys
Deployment is treated as reproducible static delivery; production infrastructure is future work.
