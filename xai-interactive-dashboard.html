Faithfulness check

Cue-removal sensitivity

For each example that cites at least one cue, the evaluator masks the cited cues and re-scores the original predicted intent. A case counts as sensitive when that raw score decreases. Abstentions cite no cues, so they are excluded from the denominator.

100% sensitivity (30 of 30 applicable examples)

For an additive scorer this is expected by construction: removing a cited cue always lowers its score. It is an implementation sanity check, not evidence of explanation helpfulness or generalization.

Interpretation

Limitations

Small set

Hand-authored examples are useful for regression testing but cannot establish generalization. The cue lists were written alongside the examples, so perfect scores are expected.

Rule model

Feature attribution is exact for this scorer because the explanation is derived from its own weights.

Future neural evaluation

A trained classifier or LLM/RAG system would require model-specific attribution and external evaluation protocols.

Evaluation protocol is intended for reproducibility and research iteration, not performance marketing.
